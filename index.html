arxiv-daily

用 Python 的 arxiv 库按关键词从 arXiv 抓取新论文。关键词为 RAG、Retrieval-Augmented Generation、Computer Vision；每次每个关键词最多 15 篇，按提交时间排序。结果写入 data/papers.json，并据此重写 README 的 Daily Papers 列表；工作流还会导出 data/papers.csv。GitHub Actions 可定时或手动运行 fetch_arxiv.py。仓库描述：自动更新 RAG、CV 相关论文。

Restaurant-Management-System

Flask 餐厅管理信息系统，数据库为 Microsoft Access（.accdb），经 pyodbc 连接。员工可登录登出。仪表盘展示顾客、订单、库存总量、今日订单、近期订单与低库存预警。支持顾客、菜单、库存（关联供应商）、订单、员工的查看与增删改。报表包括销售、顾客、菜品、库存、员工、财务概览、季节性销售与食物浪费分析，并可用 Pandas / NumPy 按历史数据做简单销量与客流预测。前端为 HTML / CSS / JavaScript（Jinja2），缓存为 Flask-Caching SimpleCache。应用入口是 TESY.py。

RAG

  • Python
  • RAG

RAG

面向高等教育知识问答的研究型 RAG 幻觉评估框架，用来比较 Non-RAG baseline 与 RAG 两条生成链路，而不是做成在线问答产品。流程覆盖语料准备、知识切分、索引构建、混合检索、双链路生成、自动评测与结果汇总。检索融合稠密向量、BM25 与 RRF。主线任务基于 OpenStax 教材问答；另有 FActScore 长文本事实生成作为补充验证。配置示例使用 deepseek-chat（temperature 0）做生成，嵌入可用 BAAI/bge-m3，评测可走 RAGAS 与 FActScore。

paper-copilot

管理学实证研究选题助手的 MVP：选题构思、PROCESS 风格模型构建，以及面向中文核心期刊的候选排序。当前能把输入主题分成强支持或通用模式，生成 8 个研究候选，将其中一个扩展为带假设的理论模型，并导出 Markdown 大纲。强支持领域包括数字化 / AI / 算法管理、组织支持 / 压力、创新 / 知识分享 / 建言。技术栈为 TypeScript。支持 OpenAI 兼容 API（如 OpenAI、DeepSeek、通义兼容网关）；未提供 API key 时回退到确定性本地 stub。密钥可写在 .env.local，或在前端设置面板填写并保存在浏览器 localStorage。首页带 LLM 设置，另有 /settings，可用「测试连接」调用 /api/test-llm。
